Assistive Menu Tool

Botão flutuante de acessibilidade para Android. Acesse ações do sistema com um toque, de qualquer tela.

DISPONÍVEL NO F-Droid

v1.3 · Código fonte no GitHub

⟲

Botão arrastável

Mova o botão para qualquer posição da tela. Ao soltar, ele se encaixa automaticamente na borda mais próxima.

⚡

10 ações rápidas

Início, Voltar, Recentes, Bloquear, Volume, Screenshot, Notificações, Painel Rápido e mais.

⚙️

Configurável

Ajuste opacidade, tamanho do botão e escolha quais ações aparecem no menu.

◎

Sem root & Privado

Usa apenas APIs públicas do Android. Funciona a partir do Android 7.0 (API 24) sem coletar dados.
